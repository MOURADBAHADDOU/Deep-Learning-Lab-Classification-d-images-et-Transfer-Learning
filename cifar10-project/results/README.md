# Résultats

- `figures/<modèle>/` : courbes d'apprentissage, prédictions d'exemple, matrice de confusion, erreurs
- `figures/comparison/` : comparaison des cinq modèles
- `metrics/<modèle>/` : historiques d'entraînement et métriques (`.joblib`)
- `metrics/test_accuracy_summary.csv` : résumé des performances sur le jeu de test
